五个主页面、项目创建与访问凭据弹窗的界面设计已成稿。本轮完成正式控制台的字号、触控尺寸、窄屏操作入口、文字对比和审计能力文案修正，并提供[可独立打开的交互预览](gui-preview.html)。真实浏览器的桌面、手机布局验收仍待执行，不能以此设计交付替代整个平台的最终验收。

## 视觉规范

保留深海军蓝导航、浅灰蓝工作区、白色内容面板和青色操作强调。重要性通过字号、位置、留白及按钮强调表达，状态同时使用文字，避免仅靠颜色判断。

| 元素 | 正式控制台规范 |
|---|---|
| 页面标题 | 桌面约 28–39 px；窄屏约 30 px |
| 内容标题 | 18 px，次级标题 16 px |
| 常规操作和字段标签 | 14 px；可编辑字段 16 px |
| 次要文字 | 最小 12 px |
| 操作命中区域 | 按钮与可编辑字段高度至少 44 px；手机导航至少 48 px |
| 控件圆角 | 10 px；内容面板 14 px |
| 主要颜色 | 导航 #071727，正文 #142433，次操作 #007d94 |
| 状态颜色 | 成功文字 #126747，等待文字 #925600，错误文字 #b82e41 |
| 键盘焦点 | 按钮与导航有可见轮廓；字段保留聚焦反馈 |
| 长内容 | 标题与名称换行；数据表和结果区可局部滚动 |
| 动画 | 尊重减少动态效果设置 |

## 响应式规则

| 宽度 | 正式控制台布局 | 待验收重点 |
|---|---|---|
| 大于 1050 px | 240 px 侧栏；三列工作区；数据列表与详情分栏 | 表单、模型指标与任务栏的密度和对齐 |
| 761–1050 px | 保留侧栏；两列工作区；数据资产与详情上下排列；压缩顶栏次要信息 | 项目名称、主操作与长标题不挤压 |
| 431–760 px | 菜单展开侧栏；内容改为纵向；保留“新建项目” | 所有关键操作可触达；无整页横向滚动 |
| 320–430 px | 单列内容；指标两列；顶栏控件紧凑排列 | 中文长名称、键盘弹起、表单输入和审批操作 |

手机布局按 CSS 视口验收，不能用硬件像素分辨率推定。目标包括 S24 Ultra 的实际浏览器视口，以及 360、390、430 px 窄屏样本。交互预览在 660 px 以下采用换行导航，方便同屏查看五个页面；正式控制台使用折叠菜单。

## 状态与边界

- 加载：保留模块标题和操作上下文，显示读取状态；正式控制台采用真实请求结果。
- 空态：告诉用户下一步操作，不伪造项目资产；预览提供一个明确标记的空项目。
- 提交：正式按钮在操作期间忙碌，避免重复提交；预览只展示状态变化。
- 错误：使用可读提示，保留能修正的输入；连接未配置与实际运行失败分别说明。
- 隔离：切换项目或令牌后清空旧身份数据，忽略先前请求的迟到响应。
- 审批：等待状态可以恢复；已处理审批不能再次操作；正式令牌模式要求独立审核身份。
- 到期：停止提供过期部署的预测入口；后端拒绝继续调用。
- 审计：表述为本地哈希链核对，未声称能够抵御数据库管理员重写。

工作流目前使用 JSON 编辑并预览结构；拖拽节点画布、数据清洗可视化规则编辑器、多模态标注、GPU 与 MCP 管理不在此 GUI 已实现范围。

## 交付与复现

- ard/static/index.html、style.css、app.js：正式应用控制台。
- docs/gui/preview-fragment.html：可编辑设计预览源。
- docs/gui/gui-preview.html：独立预览，无需启动后端。
- scripts/build_gui_preview.py：从源生成独立预览。
- docs/gui/test_preview.cjs：预览交互检查，使用 jsdom，属于 DOM 单元测试。
- docs/evidence/gui-design.json：本轮检查结果与明确未执行项。

~~~bash
python scripts/build_gui_preview.py
node --test tests/test_ui.mjs
~~~

可在单独验证目录安装 jsdom@30.0.1，通过 NODE_PATH 指定依赖目录后运行预览检查；使用 Node.js 24.15 或更高的 24.x 版本，不影响正式应用和原有 Node 20 测试。

~~~bash
mkdir -p /tmp/ai-rd-gui-check
npm install --prefix /tmp/ai-rd-gui-check --no-audit --no-fund jsdom@30.0.1
NODE_PATH=/tmp/ai-rd-gui-check/node_modules node docs/gui/test_preview.cjs
~~~
