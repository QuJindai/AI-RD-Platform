# v0.2.0 需求覆盖与后续验收

本表记录独立项目在五个软件域及硬件域中的实际覆盖。原始要求涉及完整研发平台、集群与硬件交付，本次完成可在本机运行的功能开发及适配接口，不能替代目标环境的逐条验收。公开源码、测试和报告仅使用通用描述与合成数据。

“已实现”表示存在可执行逻辑和明确验证；“适配待实测”表示代码与协议验证已有，尚未连接真实目标服务；“后续范围”未通过占位界面宣称完成。具体证据见[本轮验证记录](verification-v0.2.md)。

## 后续验收条件

- 提供目标模型服务、数据库和 MCP 环境后，验证真实连接、认证、超时和业务结果；协议模拟测试只证明适配行为。
- 提供 Docker 与可信镜像，执行真实容器创建、暂停、恢复、停止、超期回收和重启归属核验。
- 按原始硬件清单提供 GPU/NPU/集群资源，再开发和验收对应训练、调度、转换与隔离能力。
- 在允许访问的目标浏览器和设备执行布局、触控、下载、媒体播放及可视化编辑验收；未绕过当前预览访问策略。
